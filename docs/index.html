Download

  1. Download LogoToggle.zip and unzip it.
  2. Move LogoToggle.app to Applications.
  3. Open it. The first time, macOS will block it because it isn't notarized. Go to System Settings → Privacy & Security and click Open Anyway.

Or clear the quarantine flag in Terminal:

xattr -dr com.apple.quarantine /Applications/LogoToggle.app

Build from source

Needs the Xcode Command Line Tools. Apps you build yourself skip the Gatekeeper prompt.

git clone https://github.com/JamesFergus2000/LogoToggle.git && cd LogoToggle && ./build.sh --install

To start it at login, add it in System Settings → General → Login Items.

Questions.

Which Macs does it work on?

MacBook Pro models with the PROLED XDR Display and the illuminated logo, running macOS 27 or later. On other Macs there's no logo light to control.

Is it safe?

It only sends the logo-light settings to the macOS brightness service (and, during Breathe, tells the keyboard backlight to stay lit). It needs no admin rights, installs nothing else, and the whole app is a single Swift file you can read on GitHub. Quitting it, or choosing Stop, puts the logo back the way it was.

Could a macOS update break it?

Possibly. It uses an undocumented system interface. If that disappears, on/off falls back to the command from Apple's support article, which asks for your password, and the effects stop working until there's an update.

Why isn't it on the Mac App Store?

Apps on the App Store can't use private system interfaces, which is the only way to control the logo without a password.

Can I set the logo's brightness?

Not in LogoToggle. If you want brightness, sound-reactive mode, Morse code or Control Center controls, use LogoLight, the project whose research LogoToggle builds on.
