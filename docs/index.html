Glowing logo control for MacBook Pro

Light it up.
From behind.

LogoToggle is a free menu bar app for the glowing Apple logo on the new MacBook Pro. Turn it off, turn it on, make it breathe or make it strobe.

Install LogoToggle View on GitHub

01 · Off

Lights out.

Watching a film, or just want a stealthier Mac? Turn off the glowing Apple logo from the menu bar and it stays off, even after you restart.

02 · On

Back on.

One click brings the glow back. It still follows your screen brightness and the light in the room, just as macOS intended.

03 · Breathe

Let it breathe.

A slow, smooth fade in and out, using the light's own hardware fades. Try the speeds below.

04 · Strobe

Or make it flash.

Hard on, hard off, up to four times a second. Perfect for a party, less so for a meeting.

Install in one line.

Open Terminal, paste this, press Return. LogoToggle downloads, installs into Applications and appears in your menu bar.

curl -fsSL https://jamesfergus2000.github.io/LogoToggle/install.sh | sh

Read the install script before you run it. It's under 50 lines.

Prefer a download?

  1. Download LogoToggle.zip and unzip it.
  2. Move LogoToggle.app to Applications and open it.
  3. macOS blocks it the first time, because it isn't notarized by Apple. Go to System Settings → Privacy & Security and click Open Anyway.

Build it yourself

One Swift file, about 250 lines, no dependencies. Needs the Xcode Command Line Tools.

git clone https://github.com/JamesFergus2000/LogoToggle.git && cd LogoToggle && ./build.sh --install

Needs a MacBook Pro with PROLED XDR Display and macOS 27 or later. To start it automatically, add it in System Settings → General → Login Items.

Questions.

How do I turn off the glowing Apple logo on my MacBook Pro?

With LogoToggle, click its menu bar icon and choose Turn logo off. Without an app, you can use Apple's Terminal command; see our step-by-step guide.

Can I change how bright the logo is?

macOS doesn't have a brightness setting for the logo. It dims and brightens automatically with your screen brightness and the light in the room.

Which Macs have the illuminated logo?

MacBook Pro models with the PROLED XDR Display, running macOS 27 or later. On other Macs there's no logo light to control.

Could a macOS update break it?

Possibly. LogoToggle uses an undocumented part of macOS. If that changes, on/off falls back to Apple's documented command and the effects stop until there's an update.

Why isn't it on the Mac App Store?

App Store apps can't use undocumented system interfaces, which LogoToggle relies on.
